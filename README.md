# 🍔 Food Ordering App

A full-featured **Food Ordering Application** that allows customers to browse food items, add them to a cart, place orders, and track their orders. The system also provides dedicated dashboards for **Administrators** and **Delivery Personnel**.

## 🔐 Authentication

The application supports user authentication with Login and Register functionality.

Users can:

- Create a new account
- Login securely
- Select their account type
- Access different dashboards based on their role
- Switch between languages
- Toggle between Light and Dark mode

---

## 🍔 Food Menu

Customers can browse available food items including:

- Beef Burger
- Pizza
- Sushi
- Taco
- Chicken Burger
- Salads
- And more

Each food item includes:

- Food image
- Food name
- Description
- Price
- Add to Cart functionality

---

## 🛒 Shopping Cart

The shopping cart allows users to manage their selected food items بسهولة.

Features include:

- Add items to the cart
- Increase item quantity
- Decrease item quantity
- Remove items
- Calculate the total price
- Checkout and place an order

---

## 📦 My Orders

Customers can view their orders and track their status.

The order page displays:

- Ordered items
- Quantity
- Individual prices
- Total order information
- Order status
- Cancel order functionality

---

## 👨‍💼 Admin Dashboard

The Admin Dashboard allows administrators to manage customer orders.

Admins can:

- View all orders
- Review order details
- Approve orders
- Cancel orders
- Monitor order status

---

## 📊 Admin Reports

The Reports section provides important statistics about the application.

Including:

- Total Orders
- Completed Orders
- Pending Orders
- Total Revenue

---

## 🚚 Delivery Dashboard

Delivery personnel can view available approved orders.

Features include:

- View available orders
- View order details
- See customer information
- View ordered food items
- View order prices
- Take an order for delivery

# 👥 User Roles

The application supports multiple user roles.

### 👤 Customer

Customers can:

- Browse foods
- Add food to the cart
- Manage cart items
- Checkout
- View their orders
- Cancel pending orders

### 👨‍💼 Admin

Administrators can:

- View all orders
- Approve orders
- Cancel orders
- Monitor the ordering system
- View reports and statistics

### 🚚 Delivery

Delivery users can:

- View approved orders
- Check order details
- Take available orders
- Manage delivery tasks
